# GoreeCloud Metrics — Objectives

**Development goals, not release assertions:**

1. Enable private, opt-in, low-overhead host monitoring with historical trends and explainable connection state.
2. Support accessible React web, genuine Flutter Linux desktop and Flutter Android interfaces.
3. Protect host data by default with strong per-agent authentication, limited disclosure, configurable retention and transport security.
4. Provide reliable metrics and actionable signals without requiring remote execution, SaaS, ads or trackers.
5. Adopt GoreeCloud UI, GoreeShield, Wardveil, Identity and Mesh interfaces when verified and supported.
6. Make installation, upgrades, rollback, backups, tests, diagnostics and eventual release repeatable for a sole maintainer.
