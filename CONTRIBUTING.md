# Contributing

Discuss major changes in a GitHub issue. Submit focused, reviewable PRs with tests and updated capability status; CI should pass before merge. Do not commit passwords, real hostnames, operational IPs, API keys, certificates or secrets. Respect all upstream licenses and keep third-party notices current.

Do not create standalone changelog records or CHANGELOG.md in this repository. GoreeCloud change history is managed exclusively through the authorized GoreeCloud Changelogs CLI/MCP.

Do not claim Stable readiness from source or CI alone. Linux, Android and web each require independent acceptance evidence.
